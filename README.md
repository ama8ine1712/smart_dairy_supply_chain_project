# AI-Driven Smart Dairy Supply Chain Optimization — Complete Project Folder

## Quick Start
1. Run the standalone 6-tab web dashboard on localhost (zero dependencies):
   python start_localhost.py
   -> Opens http://127.0.0.1:8080/index.html

2. Run the full FastAPI + SQLite/PostgreSQL backend + live IoT simulator:
   cd smart_dairy_backend
   pip install -r requirements.txt
   python run_all.py
